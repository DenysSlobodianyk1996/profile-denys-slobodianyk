# Glossary

**AI visibility**: Being named, described or cited when an AI assistant (ChatGPT, Perplexity, Gemini, Claude, Copilot) answers a question about frontend developers.
_Avoid_: GEO (an acceptable alias, but easily misread as "geography").

**Prompt panel**: The fixed set of questions put to several AI assistants on a regular schedule to measure AI visibility. The questions stay the same from run to run so results can be compared.

**Positioning**: The titles Denys is presented under, in priority order: Senior Angular Developer, Senior Frontend Developer, Middle React Developer, Junior Vue Developer. Every on-site and off-site profile repeats these titles word for word.
_Avoid_: Mixing seniority levels within one framework (for example "Middle Angular").
